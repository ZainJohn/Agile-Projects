## Website

The e-commerce site (`docs/`) is a responsive smart watch store built with HTML, Bootstrap, and custom CSS.

| Page | Description |
|---|---|
| **Home** (`index.html`) | Hero slider, product showcase, about section, features, testimonials, contact form |
| **Products** (`products.html`) | Product catalog with pricing grid |
| **Orders** (`orders.html`) | Order history with status tracking and summary |
| **About** (`about.html`) | Company information |
| **Contact** (`contact.html`) | Contact form and details |
