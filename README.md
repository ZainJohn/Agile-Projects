# Agile-Projects

**E-commerce Smart Watch Website – Agile Project Management**

A university group project demonstrating agile project management practices through the development of a smart watch e-commerce website. The project follows an iterative agile methodology across three sprints/iterations, covering stakeholder analysis, project planning, risk management, and delivery of a functional responsive website.

## Website — Smart Watch Store

The e-commerce site (`docs/`) is a responsive smart watch store built with HTML, Bootstrap, and custom CSS. It was developed collaboratively by the team, with each member owning specific pages.

| Page | Description |
|---|---|
| **Home** (`index.html`) | Hero slider, product showcase, about section, features, testimonials, contact form |
| **Products** (`products.html`) | Product catalogue with pricing grid |
| **Orders** (`orders.html`) | Order history with status tracking and summary |
| **About** (`about.html`) | Company information |
| **Contact** (`contact.html`) | Contact form and details |
